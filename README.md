# Fantasy Football Snake Draft Simulation

This example demonstrates the "snake draft" mechanism, a core component of fantasy sports leagues. It simulates multiple teams picking players from a pool, where the draft order reverses each round to ensure fairness. The output shows the round-by-round picks and the final rosters for each team.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal using `python main.py`.
